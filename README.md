# IT Ops | Αργύρης Κάραλης

Καλώς ήρθατε στο αποθετήριο του **IT Ops**! Αυτό το project είναι μια επαγγελματική web εφαρμογή / portfolio που παρουσιάζει τις ολοκληρωμένες λύσεις IT, τις ψηφιακές υπηρεσίες και τα έργα του Αργύρη Κάραλη (IT & Digital Solutions Consultant).

## 🚀 Live Website
Μπορείτε να δείτε την ιστοσελίδα live εδώ:  
https://argiris-karalis.github.io/itops/

## 🛠️ Τεχνολογίες που χρησιμοποιήθηκαν
*   **HTML5** - Δομή περιεχομένου με προσβασιμότητα & SEO meta tags
*   **CSS3** - Responsive σχεδιασμός, Bento Grid layout, custom typography (Google Fonts) & animations
*   **JavaScript** - Διαδραστική λειτουργικότητα (Interactive Service Wizard για Viber, Lightbox gallery, Bento toggle, dynamic content & counters)

## 📁 Χαρακτηριστικά & Δομή
*   **Δίκτυα & Υποδομές IT:** Σχεδιασμός, εγκατάσταση και αριστοποίηση δικτύων & συστημάτων.
*   **Digital & Web Solutions:** Δημιουργία σύγχρονων ιστοσελίδων & παρουσίαση portfolio έργων.
*   **Συμβουλευτική & Τεχνική Υποστήριξη:** Remote & On-site τεχνική υποστήριξη.
*   **Interactive Service Wizard:** Διαδραστικό εργαλείο 3 βημάτων για άμεση επιλογή υπηρεσίας και επικοινωνία μέσω Viber.
*   **Bento Grid Pricing & FAQ:** Ενδεικτικός τιμοκατάλογος (Οικιακές & Εταιρικές υπηρεσίες) και συχνές ερωτήσεις.
*   **Language Switcher:** Υποστήριξη διπλής γλώσσας (Ελληνικά / Αγγλικά).
*   **Fully Responsive Design:** Βελτιστοποιημένο για κινητά, tablets και desktops.
